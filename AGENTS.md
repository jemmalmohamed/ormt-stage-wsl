# Consignes du dépôt

## Documentation de l’installation

Le fichier `README.md` constitue la documentation de référence pour
l’installation d’ORMT Stage sous Windows et WSL. Toute modification du parcours
d’installation, des prérequis, des commandes, des options ou du comportement
des scripts doit être documentée dans ce fichier au cours du même changement.

La documentation doit rester en français, décrire les commandes dans leur ordre
d’exécution et signaler clairement les opérations destructives ou celles qui
modifient la configuration WSL de la machine.
